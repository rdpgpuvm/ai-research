## 🆕 New Use Cases

### Agentic Memory Layering
Building on Fava Trails' approach, new systems are emerging that use version control (Jujutsu/Git) as an agentic memory layer. This solves the "memory poisoning" problem where agents hold contradictory beliefs by implementing:
- Draft isolation for uncertain memories
- Trust gates before committing to beliefs
- Supersession chains for belief evolution

### MCP Server Testing Without AI
Ocarina demonstrates that MCP servers can be tested and validated using YAML-based playbooks without any LLM involvement. This enables:
- Deterministic testing of agent toolchains
- Regression testing for MCP server updates
- Human-readable test documentation

### Text-Based Agent Sessions
The text-files-as-ui approach enables:
- Version-controlled agent sessions
- Audit trails for compliance requirements
- Human debugging of agent behavior
- Reproducible research experiments
